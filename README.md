Para inicializar el servidor Node.js y abrir la pagina ejecute el archivo "iniciar_windows" o "iniciar_mac_linux" dependiendo del software que usted posea.
La pagina se abrirá automáticamente una vez abierto el servidor en localhost a no ser que no haya utilizado el archivo de ejecución automática y lo haya abierto de forma no convencional.
